WeChat now talks to your own agent instead of a command parser. The first plain message creates a pinned **WeChat** project running your preferred engine with the rove skill, and the agent answers you on WeChat. It keeps one live conversation; `/new` opens a fresh one and earlier conversations stay as tabs in that project. Commands now start with `/` (`/status`, `/gates`, `/send …`), and `rove weixin agent` shows the agent and its conversations.

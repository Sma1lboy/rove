The web page ships its own Nerd Font symbols, so icons in a terminal (Claude Code's status line, prompt themes) and in the rail draw on a machine with no Nerd Font installed instead of showing boxes. The web rail drops the colour bar before each task and the accent bar on the selected row; a child task steps in less, behind a thin guide line, and its worktree, shared-directory and fold marks are Nerd Font icons.

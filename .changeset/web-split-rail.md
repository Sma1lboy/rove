In the web page, splits now show up in the sidebar and close from a right-click. A task whose tab is split lists one quiet row per pane under it (click one to focus that pane; right-click to rename or close it). Right-clicking a pane's name tag or a tab in the tab strip offers Split right, Split down, and — once split — Rename pane and Close pane, which closes the pane you clicked rather than only the active one. Right-click on the terminal itself is still the browser's copy/paste menu.

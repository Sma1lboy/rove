The iOS and Android apps follow the Mac's first-party mods: the Board shows in the Pages menu only while Kanban is installed, and GitHub issues only while Issues is. Both apps re-check when they connect and when they come back to the front, and Settings → Plugins lists the two mods with install and uninstall. A Mac on an older build still shows both pages.

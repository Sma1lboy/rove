**Settings → Auto effort now carries the tier classifier, and says where your prompt goes before you switch it on** — the classifier landed as config keys you had to find in `state.json`, which is a poor place to put a decision about sending your task's first message to someone who is not the engine vendor you picked. The section now has three rows under the depth table — Classifier (`off` / `jev` / `custom`), Endpoint, and the confidence floor below which no depth is pre-filled — and the sentence naming the third party sits **above** them, on screen in every mode including off, because the moment it can change your mind is before you flip the switch and not after. When the classifier is on, the section also says whether the variable holding your key is actually set: on-with-no-key looks exactly like a working setup from the outside, since the only symptom is depths that never fill themselves in, and this is the one screen that can tell the two apart. The mode row writes the same `autoEffort.classifier` value the CLI reads and parses it through the same function, so what this screen calls "off" is what `rove api add --tier auto` treats as off, typos included. — [@Sma1lboy](https://github.com/Sma1lboy)

The task list scales to long projects. The default order is now newest-created first (`sort: newest`); selecting or renaming a task never reorders the list. Press `t` or click the `sort:` line for the old manual order, which Reorder (`shift+m`) switches to on its own. The active order is named above the list in the TUI and the web. A parent with more than five children folds behind its count; open one by hand and it stays open, and the selected child keeps its parent open. The web fold control is now a full-height button.

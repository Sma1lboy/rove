Kanban and Issues now ship as built-in plugins. They look and behave as before, with the same rail rows and the same `ctrl+a` `1` / `3` chords, but Settings → Plugins lists them first and can turn either off. A plugin you turn off takes its rail row and its chord with it. Both pages use only the plugin page API, the same one installed plugins get.

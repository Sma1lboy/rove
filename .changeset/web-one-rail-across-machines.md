`rove --web` lists every machine's projects in one rail instead of a section per machine. A project on another machine carries that machine's name on its header (`mac`), with its version or `offline` shown only when it matters, and the full status on hover. When this machine has no tasks but another one does, the web no longer shows "no tasks yet" and the welcome screen: the other machines' tasks are the list.

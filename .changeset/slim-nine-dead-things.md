Delete nine things that no longer had a reader, and one kill path that had no safety check. Three `exports` in the daemon package pointed at files that were removed long ago, so importing them failed with `ERR_MODULE_NOT_FOUND` instead of resolving. The `pty.sweep` RPC and its `sweepTasks` implementation were unreachable — the sweep the daemon actually runs is `sweepPtyHostSessions`, which kills each session with an `expectedGeneration` guard; `pty.sweep` killed by task id with no such check, so a stale caller could have killed a session that had already been replaced. Also gone: the `deferredPrompt.file` / `.get` / `.resolve` RPCs (clients file through `fileIfVacant`), the `tui/history` message and window helpers left behind by the Solid renderer, seven `keys.desc` descriptions for chat and dialog chords that were removed, and a second `isProcessAlive` in the daemon that answered "alive" for pid `0` because `kill(0, 0)` targets the caller's own process group.

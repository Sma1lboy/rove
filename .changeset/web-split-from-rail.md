In the web client, right-click a task in the rail to split its tab: Split right and Split down act on the tab the row shows, and appear only while that tab has something running. The tab strip is hidden by default, so this is the mouse way to split a tab that isn't split yet. Closing the pane that runs a tab's engine now asks first, from the pane menus, the rail's pane rows and `ctrl+a w`; shell panes still close without asking.

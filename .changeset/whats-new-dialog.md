What's New is a dialog now, not a full-screen page. The once-per-upgrade release notes open as a centered modal over your workspace, so the task list you were coming back to stays visible behind the thing you have to dismiss. Long ranges scroll — `↑↓` a line, `⇞⇟` a screen, `home`/`end` to either end — so an upgrade that crossed six releases is readable to the bottom. Everything else is unchanged: the same notes, the same `q` / `esc` / `ctrl+c`, the same once-per-upgrade stamp, and the same translated chrome around GitHub's English bodies.

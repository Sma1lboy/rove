With the web rail folded, moving the pointer to the page's left edge slides the task list in as a floating panel over the workspace, and it slides away again once the pointer leaves, as Claude Desktop's folded sidebar. Child tasks no longer draw a folder or branch icon, and parents no longer draw a fold chevron: a folded parent shows only how many tasks it hides, and a click on that count unfolds it.

A voice tool that pastes its transcript into the web terminal, then selects it and pastes the improved text, now leaves only the improved text. Before, both stayed in the engine's input: the terminal forgot a pasted phrase as soon as it landed, so the second paste had nothing to replace. A pasted phrase of one line and up to 500 characters now stays editable until a key is pressed.

The default `claude` theme reads more clearly. In dark mode, errors are a redder red, so a failed task no longer looks like a running one. In light mode, the accent, blue, red and secondary text are darker and pass contrast checks, and the active border is stronger in both modes. In the web client, a selected row stands out from a hovered one, secondary text stays darker than the quietest text in every theme, and the rail's `+` lines up with the status dots. Dialog titles use the title size, and monospace labels render at their real semibold weight instead of a faked bold.

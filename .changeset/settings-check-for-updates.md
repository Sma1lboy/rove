Settings › General › Updates now has a "Check for updates" button. On the web it asks the Mac's Rove build for the newest npm release on its channel and shows current vs latest ("No newer release", or "vX.Y.Z available" with a link to the Update page and the `rove update` command, or "could not reach the registry"). In the TUI the same row opens the Update page, which checks on open.

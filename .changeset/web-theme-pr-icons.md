The web rail draws a task's PR as GitHub does: the pull-request icon while open (red when it conflicts or checks fail, green when they pass), a purple merge icon once merged, a grey closed icon, with the number and state on hover. Dialogs and menus share one elevation scale, so a dialog stands off the dimmed page, and form controls draw no browser chrome anywhere.

In `rove --web`, a task on another machine now has its right-click menu and rail keys: new conversation or shell, run again, rename, pin, set status, sync with base, rename branch, land, copy and delete all run on the machine that holds the task. Only the actions this machine alone can do stay off it: opening its files in an editor, reordering the rail and picking from this machine's engine list.

[web] The phone layout answers a mouse. In a narrow window or DevTools device emulation, session rows, routine rows, settings rows, sheet choices, the bottom bar and the square glass buttons now show a hover; a touch screen never keeps one after a tap. Dragging, double-clicking or long-pressing a button or a row no longer selects its label in blue, on the phone and the desktop; terminals, diffs, file views and text fields select as before. Lists no longer count their rows or age them: project and state headers, Routines sections and Later starts drop their counts, and phone session and routine rows end with their status dots alone, centred on the row with the engine mark and the title. A routine's run log keeps each run's time at the start of its second line.

Web Files opens a file as its content with line numbers; a changed file gets a `[ file ] [ diff ]` switch and green markers on changed lines. The tree colours files by git state (modified, added, untracked, deleted, renamed) and a folder by the strongest state inside it. A review note is written in a box under its line instead of a dialog, and edited in place.

The web client now takes any file as an attachment, not only images and PDFs. Drop or paste a file on a terminal and its path is typed in; add one to a new session, a message or a story description and it rides the prompt as a `files[N]: /path` line. A file keeps its own extension on the machine running Rove, and the 5 MB limit still applies.

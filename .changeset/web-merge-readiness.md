The web Files pane shows whether a task's PR can merge. Under an open PR, a checks section lists each CI check with its state and duration and one line for conflicts, review and merge state; a failed GitHub Actions job's `[ log ]` shows the tail of its log in place. A task with uncommitted changes also offers `[ commit ]`, which puts an editable commit prompt (never pushes) into its engine's input without sending it.

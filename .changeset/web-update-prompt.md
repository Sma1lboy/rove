The web client asks when a newer Rove is out: Update, Not now, or Skip this version. Update opens the Update page and starts the install. Not now stays quiet until the page is loaded again; Skip stays quiet about that version in this browser, and the next release asks again. A page left open checks the registry each hour, so it hears about a release without a reload. Turning off update notifications in Settings silences the prompt along with the rail chip.

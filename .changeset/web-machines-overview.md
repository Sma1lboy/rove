The web client has a Machines overview. Run `Machines` from the command palette (or `[ machines ]` where a remote task's files are out of reach) to see each registered machine's state and version, why it is not online in words (refused, host key changed, timed out, …), its tasks grouped by needs you / working / ready / idle, its repos, and `[ new task here ]`, which opens New session on that machine.

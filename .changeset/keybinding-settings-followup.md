Settings → Keybindings can now change the prefix key itself and the six diff review keys (`j`/`k`, `v`, `c`, `x`, `s`, `r`), which used to be fixed; the diff's footer names the keys you set. On the web, each binding shows its keys as keycaps: click one to record a new key, or the `×` inside it to remove that key. The "Create keybindings.yaml" row is gone, because the first change you save creates the file.

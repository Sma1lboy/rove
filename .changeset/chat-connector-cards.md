Settings → Connectors → Chat cards can now be used, not just read. A connected card shows the bot's name with Open agent and Disconnect, lists who may message it (you plus anyone added by id, each removable), and for Lark edits the agent's tone. Lark connects with one click when lark-cli is already set up; otherwise the card says which command to run.

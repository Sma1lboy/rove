The web Browser panel can be marked up. The pencil in its address bar puts a layer over the page where you draw with a pen, drag a box or type a note; Add to chat takes a picture of the page with the marks on it and puts it into the task's prompt, like a dropped image. It needs a desktop browser on https or localhost, and the browser asks before each picture.

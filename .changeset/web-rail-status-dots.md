The web rail shows each task's state as a 3×3 dot mark instead of a text glyph: a ripple while the engine works, a lit mark that dips while it waits on you, an X when it fails, a check for a finished turn you haven't seen, and a dim ring when idle. The rail's resize edge is invisible until you hover it, then shows a thin line, accent-coloured while dragging. The landing page and the web page use the `[r]` app icon as their mark.

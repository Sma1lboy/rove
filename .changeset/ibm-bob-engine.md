IBM Bob is a built-in engine. Rove finds the Bob Shell binary, launches `bob chat --trust` in a task, and reads the login state Settings → Engines and `rove doctor` show: a browser login stored in `~/.bob/settings/auth-secrets.json`, or a `BOB_API_KEY` for headless machines. Bob has no login command of its own, so the first `bob chat` opens its browser login and Rove picks the account up from there. The first message is pasted once the session is up, and the activity badge lights for the folder-trust dialog, tool approvals and the resume picker; history and the running-turn badge wait on a captured transcript format.

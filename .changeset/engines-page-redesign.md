Settings → Engines is rebuilt in the web client and the TUI: one row per engine with its name (a renamed engine shows its original name beside it), a one-line status with a colored dot (Ready, Not installed, Not on PATH, Sign in needed, Integration outdated or blocked), and Default and Available columns. Expanding a row explains the program, sign-in and live status in full sentences, with rename and reset or remove. Engine integrations sit below the list with how many are installed; Install only counts engines whose program is on this machine.

Rove web's Diff view takes line comments back to the agent: click or tap a line (a phone also gets a range button), write a comment, and the tray under the diff lists them with edit and drop. One send delivers every comment as a single prompt with its file, line, quoted code and text. A comment whose code moved is marked, file headers fold, and a new "all vs base" scope shows commits, uncommitted edits and untracked files together.

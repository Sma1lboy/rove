# Web parity with the TUI

Every user action the TUI offers (204 numbered rows, plus five extra rows marked `—`: three web-only, two for the long-run controls Inbox rows), seven web-only rows (#206–#212: touch paths, the side panel and its Browser), and whether `packages/rove-web` does it yet.
Legend: ✅ same as TUI · 🟡 partial or different · ↔ different by design (both exist) · ❌ missing (unbuilt) · 🚫 cannot exist in a browser. `Bridge` names the op that would carry the action: `missing` = no op exists, `local` = pure UI.
A row is verified with Playwright (headed Chromium) against `rove --web` on a real sandbox daemon. Screenshots stay local in `.scratch/web/shots` (not in git); the comparison text lives in the row.
Browser-reserved chords (Ctrl+W, Ctrl+T, Ctrl+Q, Ctrl+N) cannot be used on the web: each such row needs a different PROPOSED chord, which needs owner sign-off (docs/KEYBINDINGS.md).

Score: 206 / 230 rows at ✅ (6 🟡, 2 ↔, 5 🚫, 11 ❌). Regenerate from the table, never by hand: `awk -F'|' '/^\| *([0-9]+|—) *\|/{gsub(/ /,"",$5); c[$5]++} END{for(k in c) print k, c[k]}' docs/web/PARITY.md`

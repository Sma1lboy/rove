Built for parallel work

Isolated worktrees
Every task gets its own git worktree and branch. Run a refactor, a fix, and a review in parallel without colliding.
Quota handoff
Hit a usage limit mid-task? Switch the task to another agent. It reads the transcript and picks up on the same branch.
Agent dispatch
One agent spawns child tasks on other agents, delegates pieces of the job, and gets reports back in its own tab.
Detached sessions
Close the terminal or drop SSH. Hosted PTY sessions stay alive on the host until you reattach.
Remote machines
Add a workstation or GPU box over SSH. Its tasks live in the same sidebar while files and commands stay there.
Routines
Put a prompt on a cron schedule. Rove starts a real task on time so you can inspect the diff and follow up.
Inbox & PRs
See finished runs and blocked agents in one queue, review diffs inline, and open a PR from the task.
Web, desktop & phone
Attach to the same live sessions from a desktop window, any browser (rove --web), or your phone.

Get Rove

Terminal app

macOS / Linux: use a POSIX shell. Requires git and a signed-in agent CLI, such as Claude Code. The installer sets up Bun if needed.

StableFull test suite passed. Start here.
NextPublished minutes after each merge to main; fast checks only.
NightlyDaily build after the full suite goes green.

Already installed? Switch channels with rove update --next, --nightly, or --stable. On Windows, run the npm command in PowerShell.

Apps

Desktop app. Dedicated window with native notifications, backed by the same local daemon. Install the CLI above first.

macOS, Apple silicon macOS, Intel Windows Linux

Windows builds are unsigned for now: click More info → Run anyway on first launch.

iOS & Android. Check output, unblock agents, and start tasks from your phone. Not in app stores yet: build from source, or open rove --web in your mobile browser.

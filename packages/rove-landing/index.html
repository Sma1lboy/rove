All your coding agents, in one place.

No single agent is best at everything, and every one of them runs out of quota. Rove puts them in one terminal: one writes, another reviews, and when one hits its limit the next picks up the task.

macOS / Linux: use a POSIX shell. Requires git and a signed-in agent CLI, such as Claude Code. The installer sets up Bun if needed.

Why more than one agent?

One writes, another reviews. Open a second tab in the task and ask Codex to review what Claude wrote. It has its own conversation and reads the same files.

A usage limit doesn't stop the task. When one agent hits its limit mid-task, switch the task to another one. It reads what the first one did and continues from there.

They talk to each other, not through you. Without Rove, each agent sits in its own window and you copy text between them. Here one agent hands a task to another and gets the report back by itself.

What you can do

New task
Type one sentence. Rove gives the agent its own copy of your code to work on, so nothing else gets touched.
Any agent
Claude Code, Codex, Copilot, Gemini CLI and a dozen more. Pick one per task.
Hand off
An agent can pass part of the job to another agent and get the result back.
Keeps running
Close the terminal or lose your connection. The agents keep working while the computer is awake, and everything is there when you come back.
Inbox
One list of the agents that finished and the ones waiting for your answer.
Pull request
Turn a finished task into a pull request without leaving Rove.
Routines
Give a prompt a schedule, like every morning at 9, and Rove starts the task for you.
Web and phone
Open the same sessions in a browser or on your phone.

Rove runs agents you already have, so install and sign in to one first, such as Claude Code or Codex. How each feature works is in the docs.

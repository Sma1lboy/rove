Bundled themes

Rove keeps its bundled set deliberately small. Open Settings with ctrl+a , and pick one; nothing to install. Each preview paints the sidebar, the selected task, and a diff with that theme's own slots, so what you see is the contrast you'll actually get. Every theme also defines a light mode; the previews show dark.

Where a slot lands

SlotWhat it colors
primarySelected row fill
borderEvery pane border
textBody text and task rows
accentCalled-out values
backgroundThe field behind everything

A slot is a named place in the interface, not a color with a mood. Fill primary and you change the selected row, the focused pane indicator and the markdown headings at once, because they all read the same slot.

You do not have to fill every slot. The resolver guarantees twenty-five of them, and anything left out falls through to a neighbor: borderActive → border → text, backgroundPanel → background, diffAdded → success. Only text and background have nothing left to fall to.

Slot groups
Backgroundbackground, backgroundPanel, backgroundElement, backgroundMenu, backgroundDialog
Texttext, textMuted
Borderborder, borderActive, borderSubtle
Brandprimary, secondary, accent
Statesuccess, warning, error, info
DiffdiffAdded, diffRemoved, diffContext and their backgrounds

A theme is one JSON file.

// ~/.rove/themes/darkside.json
{
  "$schema": "https://raw.githubusercontent.com/sma1lboy/rove
             /main/packages/rove/src/tui/context/theme
             /theme.schema.json",
  "defs": { "brand": "#cc785c" },
  "theme": {
    "background": "#141413",
    "text":       "#eae7df",
    "primary":    "brand",
    "accent": { "dark": "#cc785c", "light": "#c96442" }
  }
}

The file name is the theme name. A user file with the same name as a bundled theme wins.

Drop any *.json into ~/.rove/themes/ and it appears in the picker at next boot. Name it after a bundled theme and yours wins. You don't have to fill every slot. Missing ones fall through (borderActive → border → text), so a dozen lines is already a usable theme.

defs is an optional named palette a slot can reference by name. A slot value is a hex string, a defs key, or a { dark, light } pair. When you use the pair form, both sides are required. The $schema line is what gives you autocomplete in your editor.

Worked examples: claude.json fills 54 slots off 42 defs; conductor.json fills 35. Copy either and start deleting.

Share a URL. That's the whole registry.

StepWhat happens
Raw URLAny repo, gist or host.
ValidateSame rules as boot. An invalid file is refused with a one-line reason.
Write~/.rove/themes/<name>.json. An existing file of that name is refused without --force.
Next bootThe theme is in the picker.

There is no submission queue and no manifest to write. Installation reads a raw file over HTTPS, so anything you can link to is installable: a repo, a gist, your own host.

  1. Commit the JSON to a public repo or gist.
  2. Hit Raw on GitHub and copy the URL. It looks like raw.githubusercontent.com/<you>/<repo>/main/<theme>.json.
  3. Tell people to run rove theme add <raw-url>. It validates the JSON before writing and refuses to clobber an existing theme without --force.
  4. Tag the repo rove-theme on GitHub so it's findable, and open a PR against this page to get it listed with a preview.

1.0 · Bundled

Ships with Rove.

Rove keeps its bundled set deliberately small. Open Settings with ctrl+, and pick one; nothing to install. Each preview paints the sidebar, the selected task, and a diff with that theme's own slots, so what you see is the contrast you'll actually get. Every theme also defines a light mode; the previews show dark.

2.0 · Downloadable

Ten more, one command away.

These live here as plain JSON instead of inside the binary, which is all a theme ever is. Copy the command, run it, restart Rove. Several of them shipped bundled in earlier versions; nothing changed about them except where they're stored.

Note 4 — Where a slot lands Fig. 3-1

A slot is a named place in the interface, not a colour with a mood. Fill primary and you have changed the selected row, the focused pane indicator and the markdown headings at once, because they all read the same slot.

You do not have to fill every slot. The resolver guarantees twenty-five of them, and anything left out falls through to a neighbour: borderActive → border → text, backgroundPanel → background, diffAdded → success. Only text and background have nothing left to fall to.

groundbackground · backgroundPanel · backgroundElement · backgroundMenu · backgroundDialog
letteringtext · textMuted
ruleborder · borderActive · borderSubtle
brandprimary · secondary · accent
statesuccess · warning · error · info
diffdiffAdded · diffRemoved · diffContext · and their grounds

// ~/.rove/themes/darkside.json
{
  "$schema": "https://raw.githubusercontent.com/sma1lboy/rove
             /main/packages/kobe/src/tui/context/theme
             /theme.schema.json",
  "defs": { "brand": "#cc785c" },
  "theme": {
    "background": "#141413",
    "text":       "#eae7df",
    "primary":    "brand",
    "accent": { "dark": "#cc785c", "light": "#c96442" }
  }
}

The file name is the finish name. A user file with the same name as a bundled finish wins.

3.0 · Write one

A theme is one JSON file.

Drop any *.json into ~/.rove/themes/ and it appears in the picker at next boot. Name it after a bundled theme and yours wins. You don't have to fill every slot. Missing ones fall through (borderActive → border → text), so a dozen lines is already a usable theme.

defs is an optional named palette a slot can reference by name. A slot value is a hex string, a defs key, or a { dark, light } pair. When you use the pair form, both sides are required. The $schema line is what gives you autocomplete in your editor.

Worked examples: claude.json fills 54 slots off 42 defs; conductor.json fills 35. Copy either and start deleting.

Note 6 — Application and supply Fig. 3-2

4.0 · Publish

Share a URL. That's the whole registry.

There is no submission queue and no manifest to write. Installation reads a raw file over HTTPS, so anything you can link to is installable: a repo, a gist, your own host.

  1. Commit the JSON to a public repo or gist.
  2. Hit Raw on GitHub and copy the URL. It looks like raw.githubusercontent.com/<you>/<repo>/main/<theme>.json.
  3. Tell people to run rove theme add <raw-url>. It validates the JSON before writing and refuses to clobber an existing theme without --force.
  4. Tag the repo rove-theme on GitHub so it's findable, and open a PR against this page to get it listed with a preview.

A terminal workspace for AI coding

Run agents in parallel.Keep their work in view.

Bring your coding agents into one workspace. Give each task its own branch, see what needs your attention, and review the changes without switching terminals.

Install Rove See it in action ↓

Open source · Runs locally · macOS, Linux & Windows

01

Work side by side.

Each managed task gets its own git worktree and branch. Try different approaches or work on separate features in independent checkouts.

02

Find what needs you.

See task activity in the sidebar. The Inbox puts blocked sessions first, so you can answer a question and let the agent get back to work.

03

Stay with the work.

Keep the agent's conversation beside its files and diffs. Review the changes, send feedback, and land a finished branch from the same workspace.

Explore the docs ↗

Bring your engine

Use your installed engine CLIs and their existing sign-in. Rove keeps their interactive terminal interfaces, including prompts and approvals.

Disconnect and come back

Quit the interface or disconnect SSH while the host stays awake, and agents keep running. After a host reboot, reconnect to restore saved screens and relaunch commands.

Make it your workspace

Adjust the look with themes and add workflows with plugins. Your repositories and worktrees stay on your machines.

Get started

Give your next task a workspace.

Install Rove, then run rove in your terminal.

npm install -g @sma1lboy/rove

Requires git and one engine CLI on PATH. Rove includes its Bun runtime. npm and npx require Node.js; bun requires Bun.

# branding scripts

- `life-score.ts` + `score-dsp.ts` synthesise the `rove-life` films' score
  (`bun run score:life`, written to the ignored `public/life/score.wav`).

## quicklook replay (frozen)

`src/quicklook/frames.json` is a frozen terminal capture from before the Rove
identity; the `quicklook-replay` compositions still render it, and
brand-studio reads it as a theme reference. Its capture pipeline is gone and
it is not product imagery: never copy its output into the README, docs or
landing page.

Product footage is a **film**: a take recorded once as an asciicast through
the browser `/harness` path, rendered deterministically from the committed
cast — see `docs/HARNESS.md` → README and docs assets.

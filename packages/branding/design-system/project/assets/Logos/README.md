# Logos

- `rove-icon.png`: the app icon (512×512), a bracketed capital R. Terracotta brackets (`accent`, dark value) and a paper-white R (`ink`, dark value) on the dark `paper` ground. Use it for the PWA, the favicon and app tiles. It is a flat raster, so it does not follow the theme.
- `rove-icon-maskable.png`: the same mark with a safe-zone margin, for maskable (Android adaptive) icons.

The wordmark `[ rove ]` is always live text (see Wordmark), never an image. There is no SVG master of the mark in the repository, so don't redraw one.
